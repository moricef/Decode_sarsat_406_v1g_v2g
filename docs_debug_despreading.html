2. Opération XOR de despreading (lignes 895-898)

Code actuel:

for (size_t i = 0; i < DSSS_PACKET_CHIPS; i++) {
    ibdn[i] = rx_ci[i] ^ prn_i[i];  // XOR binaire
    qbdn[i] = rx_cq[i] ^ prn_q[i];
}

Questions critiques:

# 1. Vérifier le type de rx_ci et prn_i
grep -n "int8_t.*rx_ci\|int8_t.*prn_i" dsss_demod.c

# 2. Le XOR suppose des valeurs 0/1, mais rx_ci peut être -1/+1 ou 0/1
# Vérifier qpsk_demod (ligne 816) - quel format produit-il ?
grep -A20 "^static void qpsk_demod" dsss_demod.c
🔴 Problème potentiel:
  • rx_ci[i] est-il en format 0/1 (binaire) ou -1/+1 (BPSK) ?
  • prn_i[i] est-il en format 0/1 (binaire) ou -1/+1 (BPSK) ?
  • Le XOR binaire (^) ne fonctionne correctement QUE si les deux sont en 0/1

Test à faire:

// Si rx_ci et prn_i sont en -1/+1, le despreading devrait être:
ibdn[i] = rx_ci[i] * prn_i[i];  // Multiplication, PAS XOR

// Si rx_ci et prn_i sont en 0/1, le XOR est correct:
ibdn[i] = rx_ci[i] ^ prn_i[i];

3. ML Decoding avec seuil (lignes 907-918)

Code actuel:

int threshold = DSSS_SPREADING_FACTOR / 2;  // 256/2 = 128

for (int bit_idx = 0; bit_idx < DSSS_PACKET_BITS / 2; bit_idx++) {
    int i_sum = 0;

    for (int chip = 0; chip < DSSS_SPREADING_FACTOR; chip++) {
        i_sum += ibdn[bit_idx * DSSS_SPREADING_FACTOR + chip];
    }

    ibits[bit_idx] = (i_sum > threshold) ? 1 : 0;
}

Analyse selon le format des données:

Format Despreading Somme si bit=0 Somme si bit=1 Seuil optimal
0/1 avec XOR ibdn[i] = rx_ci[i] ^ prn_i[i] ≈ 128 ≈ 128 ❌ Ne discrimine PAS !
-1/+1 avec multiplication ibdn[i] = rx_ci[i] * prn_i[i] ≈ +256 ≈ -256 ✅ Seuil = 0
🔴 PROBLÈME IDENTIFIÉ: Le seuil à 128 ne discrimine PAS correctement si les données sont en format 0/1 avec XOR !

Tests à faire:

OPTION 1: Si XOR avec 0/1, compter les 0 vs les 1

int zeros = 0, ones = 0;
for (int chip = 0; chip < DSSS_SPREADING_FACTOR; chip++) {
    if (ibdn[bit_idx * DSSS_SPREADING_FACTOR + chip] == 0) zeros++;
    else ones++;
}
ibits[bit_idx] = (ones > zeros) ? 1 : 0;

OPTION 2: Si multiplication avec -1/+1, seuil à 0

int i_sum = 0;
for (int chip = 0; chip < DSSS_SPREADING_FACTOR; chip++) {
    i_sum += ibdn[bit_idx * DSSS_SPREADING_FACTOR + chip];
}
ibits[bit_idx] = (i_sum > 0) ? 1 : 0;  // Seuil à 0, pas 128 !

6. Hypothèse principale

🔴 Problème le plus probable:

L'opération de despreading utilise XOR binaire alors que les données sont en format -1/+1 (ou inversement).

✅ Solution probable:

Vérifier qpsk_demod() et soit:

  1. Changer le XOR en multiplication si les données sont -1/+1
  2. Ou convertir les données en 0/1 avant le XOR

Prochaine étape:

Examiner la fonction qpsk_demod() pour déterminer le format de sortie exact.

grep -A50 "^static void qpsk_demod" dsss_demod.c
