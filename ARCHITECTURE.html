void decode_beacon(const uint8_t *bits, int length) {
  switch(length) {
    case 112/144: decode_1g(bits, length); break;
    case 252: decode_2g(bits); break;

🚨 Composant Manquant Critique

Démodulateur DSSS/OQPSK pour signaux 2G

Gap actuel:
Signal IQ (2.5 MHz) → ❌ MANQUANT → 300 bits démodulés → ✅ dec406_v2g.c

Fonctionnalités nécessaires:

  1. AGC (Automatic Gain Control)
  2. Détection préambule (50 bits alternés) avec recherche fréquence
  3. Correction fréquence grossière (Doppler ±12 kHz)
  4. Correction fréquence fine (PLL Costas)
  5. Récupération timing (Symbol Synchronizer)
  6. Résolution ambiguïté de phase (4 rotations × 2 I/Q swap)
  7. Démodulation QPSK → chips I/Q
  8. DÉSÉTALEMENT DSSS:
    • Génération PRN I/Q (LFSR x²³+x¹⁸+1, init: 0x000001 / 0x000041)
    • Corrélation XOR sur 256 chips/bit
    • Décision vote majoritaire (>128/256)
    • Entrelacement I/Q → flux bits (odd→I, even→Q)
  9. Output: 300 bits (50 préambule + 250 payload)
