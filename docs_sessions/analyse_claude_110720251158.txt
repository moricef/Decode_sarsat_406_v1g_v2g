● 📊 Construction du préambule de référence dans le démodulateur:

  Étape 1: Calcul des dimensions (ligne 819)

  num_preamble_chips = DSSS_PREAMBLE_BITS * (DSSS_SPREADING_FACTOR / 2)
                     = 50 * (256 / 2)
                     = 50 * 128
                     = 6400 chips

  Étape 2: Création du préambule QPSK (lignes 834-839)

  Crée 3200 symboles QPSK (= 6400 chips / 2):

  for (i = 0; i < 3200; i++) {
      chip_i = prn_i[i];  // Chip I au rang i
      chip_q = prn_q[i];  // Chip Q au rang i

      // Combine chip par chip en QPSK
      preamble_qpsk[i] = (chip_i + j*chip_q) × exp(jπ/4) / √2
  }

  Mapping des chips:
  - Symbole 0 = prn_i[0] + j×prn_q[0]
  - Symbole 1 = prn_i[1] + j×prn_q[1]
  - Symbole 2 = prn_i[2] + j×prn_q[2]
  - ...
  - Symbole 3199 = prn_i[3199] + j×prn_q[3199]

  Étape 3: Extraction pour détection (lignes 842-845)

  Extrait une portion raccourcie:
  preamble_detect = preamble_qpsk[200..374]  // 175 symboles
  Saute les 200 premiers symboles (convergence AGC), utilise 175 symboles.

● 🔍 Le générateur combine les chips ainsi:

  Génère 38400 samples par chip (SPS=64):

  Chip I[0]: samples 0..63 = i_prn[0]
  Chip I[1]: samples 64..127 = i_prn[1]
  ...

  Chip Q[0]: samples -32..31 (clipped) + 32..95 = q_prn[0] (décalé de -32)
  Chip Q[1]: samples 32..95 + 96..159 = q_prn[1]
  ...

  Résultat avec OQPSK (Tc/2 = 32 samples delay):

  | Samples  | I component | Q component |
  |----------|-------------|-------------|
  | 0..31    | i_prn[0]    | 0 (clipped) |
  | 32..63   | i_prn[0]    | q_prn[0]    |
  | 64..95   | i_prn[1]    | q_prn[0]    |
  | 96..127  | i_prn[1]    | q_prn[1]    |
  | 128..159 | i_prn[2]    | q_prn[1]    |
  | 160..191 | i_prn[2]    | q_prn[2]    |

  Donc chaque chip Q chevauche 2 chips I (OQPSK offset).
