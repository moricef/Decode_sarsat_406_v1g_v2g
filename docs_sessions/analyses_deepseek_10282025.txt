// Structure pour le double buffering
typedef struct {
    float complex *buffer;
    size_t buffer_size;  // = 2 × burst_samples
    size_t burst_samples; // échantillons pour 1 rafale complète
    size_t current_pos;
    bool new_data_available;
} sample_buffer_t;

// Mécanisme ping-pong
int process_sample_buffer(sample_buffer_t *buf, const float complex *new_samples, size_t new_len) {
    // Décaler les anciennes données
    memmove(buf->buffer, &buf->buffer[buf->burst_samples], 
            buf->burst_samples * sizeof(float complex));
    
    // Copier les nouvelles données dans la seconde moitié
    size_t copy_len = (new_len > buf->burst_samples) ? buf->burst_samples : new_len;
    memcpy(&buf->buffer[buf->burst_samples], new_samples, 
           copy_len * sizeof(float complex));
    
    // Rechercher le préambule sur le buffer complet (2 × burst_samples)
    return search_preamble_in_buffer(buf->buffer, buf->buffer_size);
}

## 🎯 Diagnostic Final

### **La performance à 55.3% s'explique par trois bugs critiques :**

1. **🚨 TIMING RECOVERY DÉFAILLANT** (BUG #1)
   - Échantillonnage incorrect des symboles
   - Récupération incomplète (33k/38.4k symboles)
   - SNR catastrophique (1.1 dB)

2. **🚨 DESPREADING MAL ALIGNÉ** (BUG #3)  
   - Alignement chips/PRN incorrect
   - Corrélation 0.053 vs >0.7 attendu
   - Conventions chips/PRN potentiellement inversées

3. **🚨 ABSENCE DE DOUBLE BUFFERING**
   - Architecture inadaptée aux signaux asynchrones
   - Risque de perte de parties de rafale

### **Problèmes secondaires :**
- Correction fine désactivée (BUG #4)
- Phase ambiguity résolution sous-optimale (BUG #2)
